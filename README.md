# لوحات التحكم المالية — المجموعة 2026

داشبوردات HTML تفاعلية لمتابعة قوائم الدخل الشهرية لأربع شركات (20 فرعاً)، مبنية من بيانات
[الملف الرئيسي الموحد](#مصدر-البيانات) وتُعرض مباشرة في المتصفح بدون أي خادم أو قاعدة بيانات.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | **الداشبورد التجميعي** — كل الشركات الأربع (20 فرعاً) مع فلتر تبديل بين "كل الشركات / شركة واحدة / فرع واحد" |
| `zawya-2026.html` | شركة زاوية ريال البركة (فرعا اليرموك والمصيف) |
| `riyal-baraka-2026.html` | شركة ريال البركة (الخرج، الدائري، الدمام، النسيم1) |
| `abdulrahman-2026.html` | شركة عبد الرحمن — مجموعة سلطان الرزيحي التجارية (10 فروع) |
| `aswaq-2026.html` | مؤسسة الاسواق (الاحساء، الشفا، النسيم2، لبن) |

كل الملفات فيها شريط تنقل صغير أعلى الصفحة للانتقال بين الداشبورد التجميعي وداشبورد كل شركة.

## المزايا في كل داشبورد

- فلترة حسب الفترة: شهر واحد / ربع سنوي / نصف سنوي / السنة كاملة
- تقرير مستقل لكل فرع، وجدول مبيعات شهري تفصيلي لكل الفروع
- مقارنة بين الفروع (أو بين الشركات في الداشبورد التجميعي)
- قائمة دخل تفصيلية قابلة للبحث (36 بنداً)
- صفحة "ملاحظات وانحرافات" مولّدة آليًا (خسائر تشغيلية، تذبذب مبيعات، انحراف هامش الربح، بنود مصروف غير معتادة)
- تصدير الجداول، وضع ليلي/نهاري، تصميم متجاوب للجوال

## النشر على GitHub Pages

1. ارفع كل الملفات إلى جذر المستودع (أو مجلد `/docs`).
2. من إعدادات المستودع → **Pages** → اختر الفرع والمجلد → Save.
3. سيصبح الداشبورد التجميعي متاحًا مباشرة على `https://<username>.github.io/<repo>/`.

لا حاجة لأي بناء (build) أو تثبيت حزم — الملفات HTML جاهزة للعرض كما هي، وتعتمد فقط على
Chart.js وFont Awesome من CDN عام (cdnjs).

## مصدر البيانات

البيانات مُضمَّنة داخل كل ملف (لا اتصال خارجي بقاعدة بيانات)، ومسحوبة من:
- قوائم الدخل الفعلية لكل شركة (يناير–يوليو 2026)
- الملف الرئيسي الموحد للمجموعة (تجميع الأربع شركات)

لتحديث البيانات لاحقًا، يلزم تحديث كائن `DATA` المُضمَّن في كل ملف (الأشهر، الفروع، الملاحظات)
ثم إعادة رفع الملفات.

## ⚠️ خصوصية البيانات

هذه الملفات تحتوي على **أرقام مالية حقيقية** (إيرادات، رواتب، أرباح/خسائر) لشركات فعلية.
يُنصح برفعها إلى **مستودع خاص (Private repository)** وليس عامًا، ما لم يكن هناك قرار واعٍ بنشرها.
